# Isekai Python Academy

Learn Python through a fantasy light novel. Read a chapter, write real Python in the browser, and clear the System's quests to level up.

Python runs in the browser with [Brython](https://brython.info), so no server or installation is needed.

## Run locally

Open `index.html` in any modern browser (you need an internet connection).

## Deploy

- **GitHub Pages:** push this folder to a repository → Settings → Pages → "Deploy from a branch" → `main` / root.
- **Vercel:** import the repository at vercel.com → Framework preset "Other" → Deploy. No build command needed.
